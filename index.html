BEFORE YOU RUN IT

A few things
worth knowing.

Clear answers for a tool that sits between your local server and the internet.

Does my URL stay online after I close the CLI?

The app name stays yours, but the endpoint goes offline when the CLI or local server stops. Run the same command in the project directory to reconnect.

Do I need an account to see logs?

No email account is required. Run endport code in the project directory, then enter the one-time code at workspace.endport.io/.

What does Endport store?

The workspace stores request method, path, status, timing, and transfer size for seven days. Headers and query strings are never stored. Optional redacted JSON body previews are off by default.

Can I use my own domain?

Yes. Add a subdomain in the workspace, create the CNAME and verification TXT records it shows, and verify DNS before connecting with --domain.
